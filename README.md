# Team Expulsion (Civ VI mod)

A Gathering Storm mod idea: teammates can vote to kick someone off their team mid-game. The kicked player plays on alone, and nothing else changes.

Right now it's in a feasibility spike. Civ VI has no known way to change a player's team after the game starts, so the first job is finding out if it can be done at all. There's nothing to play yet.

The mod itself (version 0.1.0, in `TX`) is now being built and tested in hotseat.

What's in here:
- TX_Dev: dev tools for the spike. Don't enable them in a real game.
- tools: install script, static checks and a log summarizer.
- tests/offline: tests that run the scripts against a fake game engine.

Requires Gathering Storm.
